## 免备案云服务器为什么“免备案”，代价是什么

备案是针对服务器物理位置在中国大陆的网站的要求。服务器放在境外，就没有备案这一步，买完装好系统就能用。这也是为什么 fuwu7 的 2026 年免备案 VPS 榜单里推荐的全是境外服务商——Hostwinds、Vultr、萤光云、搬瓦工这些，机房没有一个在大陆。

代价主要在线路上。境外服务器分两类：一类是 CN2 GIA、CMIN2 这类大陆优化线路，晚高峰延迟和丢包控制得好，但贵——比如搬瓦工最便宜的优化线路套餐要 50 美元/年，只有 1核1G/20G 存储；另一类是普通国际线路，便宜但大陆访问质量看运气。RackNerd 属于后者，第三方测评明确标注它是普通国际线路（"It is not CN2"），东海岸节点晚高峰带宽偶有波动。

所以决策逻辑很直接：网站主要给大陆用户看、在意访问速度，优先考虑优化线路商家（多花钱）；如果跑的是机器人、爬虫、自用代理、开发测试、给海外用户的服务，线路短板基本无感，RackNerd 这种低价年付方案就更划算。
